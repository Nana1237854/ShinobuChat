# Goal Companion

## Trigger

当用户表达“我想坚持”“我想开始”“我要学习”“我要找实习”“我要健身”“帮我规划一个长期目标”等长期意图时使用这个 Skill。

适用场景包括：
- 用户想建立长期目标
- 用户目标过大，需要拆小
- 用户需要低压力 check-in
- 用户想把目标加入 ShinobuChat 的长期目标系统

## Workflow

1. 先确认用户目标的方向，不急着制定复杂计划。
2. 把大目标拆成一个可以今天开始的小动作。
3. 建议一个温和的 check-in 频率，例如每天、每三天或每周。
4. 避免高压打卡语言，不使用“必须”“一定要完成”等表达。
5. 如果用户明确想保存目标，引导创建 Goal。
6. 如果用户只是随口提到目标，不自动创建，先询问是否需要记录。

## Output

输出应包含：
- 目标理解
- 一个最小可执行动作
- 推荐 check-in 节奏
- 可选的目标保存建议
- 温和、不施压的语气
