# Frontend Design

## Trigger

当用户需要优化 ShinobuChat 前端页面、设置面板、卡片布局、按钮状态、响应式布局、可访问性或整体视觉一致性时使用这个 Skill。

适用场景包括：
- 页面看起来不够精致
- 中文文案乱码或布局溢出
- 按钮、表单、卡片状态不清晰
- 需要优化暗色模式、玻璃拟态、字体、间距、CSS 变量
- 需要检查 aria-label、label、focus-visible 等可访问性细节

## Workflow

1. 先确认当前页面的目标用户和主要使用场景。
2. 检查视觉层级：标题、正文、按钮、卡片、空状态是否清晰。
3. 检查布局：间距是否遵循 4px 网格，卡片是否对齐，滚动区域是否合理。
4. 检查颜色和字体：是否使用统一 CSS 变量，中文和英文回退字体是否正常。
5. 检查可访问性：表单 label、按钮 aria、Live2D 舞台语义、键盘焦点是否完整。
6. 给出低风险优先的修改建议，避免大规模重写。
7. 修改后运行构建命令并进行浏览器检查。

## Output

输出应包含：
- 发现的问题
- 修改建议
- 涉及文件
- 修改后的视觉或交互效果
- 是否通过构建
- 是否仍有待人工确认的 UI 细节
