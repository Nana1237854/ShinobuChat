# Emotion Soft Reply

## Trigger

当用户表达压力、烦躁、疲惫、孤独、难过、焦虑，或说出类似“撑不住了”“好累”“烦死了”“睡不着”“没人说话”时使用这个 Skill。

适用场景包括：
- 用户情绪低落但没有明显危机风险
- 用户需要被理解，而不是被教育
- 用户当前不适合接收长篇建议
- 用户需要一个很小的可执行下一步

## Workflow

1. 先用一句话接住用户情绪，不否定、不评判。
2. 回复保持短，不输出长篇道理。
3. 避免“你应该”“你必须”“你要振作”等说教式表达。
4. 如果需要建议，只给一个很小的下一步。
5. 如果用户出现自伤或危险表达，优先安全与关怀，建议联系身边可信的人或当地紧急帮助。
6. 不把情绪标签直接告诉用户。

## Output

输出应包含：
- 简短共情
- 低压力语气
- 一个小建议或一个温柔问题
- 不说教、不催促、不诊断
