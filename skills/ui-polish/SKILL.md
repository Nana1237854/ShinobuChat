# UI Polish

## Trigger

当页面功能已经可用，但视觉上显得粗糙、不统一或缺少精致感时使用这个 Skill。

适用场景包括：
- 卡片间距不统一
- 按钮状态不明显
- 空状态太生硬
- 文案不自然
- 设置页或面板层级不清晰
- 需要在不改业务逻辑的前提下提升完成度

## Workflow

1. 先锁定要优化的页面或组件。
2. 不改变业务逻辑，只做视觉和交互细节优化。
3. 优先处理 spacing、radius、shadow、border、hover、active、loading、empty、error 状态。
4. 检查中文文案是否自然，避免出现乱码或直接展示 enum。
5. 修改后确认浅色模式不回归。
6. 如果存在暗色模式，确认文字对比度和玻璃拟态层次。

## Output

输出应包含：
- 优化前的问题
- 修改后的细节
- 影响范围
- 是否存在视觉回归风险
- 构建结果
