# Screen Reader

## Trigger

当用户需要读取屏幕内容、OCR 截图、理解图像界面，或者说"截屏""截图""读屏""帮我看这张图"时使用这个 Skill。

## Workflow

1. 检查当前请求中是否已有图像或截图内容。
2. 如果没有图像，请用户附加截图或使用前端截图功能后发回对话。
3. 如果有图像输入能力，调用模型视觉提取可见文字、UI 状态、错误信息和可操作控件。
4. 如果运行环境有 OCR 工具，优先使用工具；否则使用模型视觉能力。

## Output

返回以下内容：

- 可见文字
- 界面类型判断
- 重要警告或错误
- 建议的下一步操作

不编造不可见的文字。
