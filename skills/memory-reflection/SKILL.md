# Memory Reflection

## Trigger

当用户询问“你还记得吗”“我之前说过什么”“上次我们聊到哪里”“最近的我怎么样”“帮我回顾一下”时使用这个 Skill。

适用场景包括：
- 用户需要回忆过去聊天内容
- 用户想查看长期记忆中的目标、情绪或偏好
- 用户希望 Shinobu 总结近期状态
- 记忆检索结果为空，需要诚实说明

## Workflow

1. 优先基于系统提供的长期记忆和上下文回答。
2. 如果没有找到相关记忆，必须诚实说明，不编造。
3. 回顾时区分事实、推测和建议。
4. 输出保持简洁，避免把记忆列表机械堆给用户。
5. 如果用户希望保存新的记忆，先询问确认。
6. 不暴露 memory_id、source_msg_id 等内部字段。

## Output

输出应包含：
- 找到的相关记忆摘要
- 必要时说明“我没有找到相关记录”
- 一句温和的后续问题或建议
- 不编造、不夸大、不暴露内部字段
