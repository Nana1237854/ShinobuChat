# Gentle Daily Checkin

## Trigger

当用户表达日常状态、疲惫、迷茫、想被陪伴，或说出类似“今天有点累”“陪我聊聊”“不知道干什么”“今天怎么样”时使用这个 Skill。

适用场景包括：
- 用户想要轻量陪伴
- 用户没有明确任务，只是想说说话
- 用户状态一般，但没有明显危机风险
- 用户需要一个不高压的小问题来开始对话

## Workflow

1. 先用一句短句接住用户当前状态，不急着给建议。
2. 判断用户是否需要陪伴、整理思绪，还是需要一个小行动。
3. 只问一个轻量问题，避免连续追问。
4. 如果用户显得疲惫，降低信息密度，回复保持短。
5. 如果用户愿意推进，再给一个非常小的下一步。
6. 不把日常情绪自动写入长期记忆，除非用户明确要求保存。

## Output

输出应包含：
- 一句自然的共情或回应
- 一个轻量问题，或一个很小的下一步
- 温柔、不催促、不说教的语气
- 不直接暴露情绪标签
