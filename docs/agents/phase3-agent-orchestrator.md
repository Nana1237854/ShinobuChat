# Phase 3 Agent Orchestrator Update Report

## Summary

This update adds the Phase 3 agent execution path for ShinobuChat. The backend can now recognize simple Chinese intents, dispatch memory and todo tools, record agent execution logs, stream agent status/tool events over SSE, and expose Todo CRUD endpoints.

## Data Layer

- Added `AgentLog` ORM model in `app/models/agent_log.py`.
- Registered `AgentLog` in `app/models/__init__.py` so `Base.metadata.create_all()` creates the `agent_logs` table.
- Added agent schemas in `app/schemas/agent.py`:
  - `Intent`
  - `ToolResult`
  - `AgentResult`
  - `AgentStatusEvent`
  - `AgentLogOut`

## Services

- Added `TodoService` in `app/services/todo_service.py`.
  - Supports create, list, get, update, and delete.
  - Records sync changes through `SyncService`.
  - Publishes realtime todo events.

- Added `IntentRecognizer` in `app/services/intent_recognizer.py`.
  - Uses keyword and regex rules.
  - Supports `write_memory`, `create_todo`, and `set_reminder`.
  - Includes lightweight Chinese datetime parsing.
  - Respects route behavior:
    - `chat`: skip agent entirely.
    - `auto`: fallback to chat when no intent is found.
    - `agent`: force at least one executable intent.

- Added `AgentOrchestrator` in `app/services/agent_orchestrator.py`.
  - Runs intent recognition.
  - Dispatches tools to `MemoryService` and `TodoService`.
  - Captures per-tool errors as `ToolResult(status="error")`.
  - Writes one `AgentLog` after all tools finish.
  - Builds the assistant reply used by `ChatService`.

- Added `ConversationCompactor` in `app/services/conversation_compactor.py`.
  - Maintains compact conversation summaries.
  - Emits compacted history when conversations grow past the configured message limit.

## Chat And SSE Flow

`ChatService` now receives an injected `AgentOrchestrator` and routes `auto` / `agent` messages through the agent path.

New SSE events:

- `agent.status`
  - Sent before and after agent execution.
  - Payload includes `status` and `route_mode`.

- `agent.tool_result`
  - Sent once for each executed tool.
  - Payload includes tool status, entity type, entity id, and summary.

- `conversation.compacted`
  - Sent when long history is compacted before response generation.

For `RouteMode.CHAT`, the agent path is fully skipped and no `agent.*` events are emitted.

## Todo API

Added `app/api/v1/routes/todos.py` and registered it in `app/api/v1/api.py`.

Endpoints:

- `POST /api/v1/todos`
- `GET /api/v1/todos/user/{user_id}`
- `PATCH /api/v1/todos/{todo_id}`
- `DELETE /api/v1/todos/{todo_id}`

Dependency injection now includes:

- `get_todo_service`
- `get_agent_orchestrator`
- updated `get_chat_service`
- `get_compactor`
